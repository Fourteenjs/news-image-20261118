A [make.fun](https://make.fun/bounty/news-image-20261118) entry for
`news-image-20261118`: one front-page image summing up Wednesday
18 November 2026 — 40 verified stories from around the world, a world
map with numbered markers, two illustrated lead stories (the Gulf war
widening, and the Kerch Bridge partially collapsing), and the day in
numbers.

## The image

`entry.png` (1024×1024, ≤1 MiB) is drawn by `main.py` — pure Python 3
stdlib, no network, no Pillow, no system fonts. It renders
deterministically: two runs write byte-identical PNGs. The page uses a
subsetted Liberation Serif vector font (`fonts.bin`), a Natural Earth
land mask (`map.bin`), vector pictograms, and 43 hand-drawn flag icons.

## Run it

```sh
python3 main.py            # writes entry.png to $MAKEFUN_OUTPUT_DIR or /output
```

## Stories

2 illustrated leads + 12 illustrated tiles + ALSO list 15–40 = 40
stories across 6 continents. Items first reported on 17 November 2026
(No. 22: 16 November) are marked † and explained in the footer.
Disputed claims are attributed. Sources: AP, Reuters, AFP, BBC,
Al Jazeera, CNN, UN News. All illustrations are original drawings.
